Then gradient descent ▶ N3

Make loc and scale parameters, and minimise the KL with Adam

class TrainableNormal(nn.Module):
    def __init__(self, loc, scale):
        super().__init__()
        self.loc = nn.Parameter(torch.tensor(loc))
        self.raw_scale = nn.Parameter(inverse_softplus(scale))
    def forward(self):
        return dist.Normal(self.loc, F.softplus(self.raw_scale))

q = TrainableNormal(loc=4.0, scale=0.5)
opt = torch.optim.Adam(q.parameters(), lr=0.05)
for step in range(400):
    loss = dist.kl_divergence(q(), p)
    opt.zero_grad(); loss.backward(); opt.step()

A trainable $q$. The scale must stay positive, so we learn a raw number and pass it through $\mathrm{softplus}(r) = \log(1 + e^{r}) > 0$.

Start far away: $q = \N(4, 0.5^2)$, the PML notebook's starting point.

The loop. Every step: compute the KL, backpropagate to loc and raw_scale, take a step. Nothing here is specific to Gaussians except the formula inside kl_divergence.

The loss is a KL; the parameters are a distribution's. Otherwise this is any training loop you have written.

The same in two dimensions · goal G6, first look ▶ N3

A correlated target: a diagonal $q$ cannot tilt, so it shrinks

Target $p$: two dimensions, unit widths, correlation $\rho = 0.9$ (blue).

Diagonal $q$ (one width per axis, no correlation): best width {{vik.g2d.diag_sd}} $= \sqrt{1-\rho^2}$, KL {{vik.g2d.diag_kl}}.

Full covariance $q$, $\Sigma = LL^\top$ with $L$ lower-triangular: matches $p$ exactly, KL {{vik.g2d.full_kl}}.

$\KL(q\|p)$ prefers a $q$ that is too narrow over one that spills outside $p$. Part 2's lesson, in 2-D.

PML notebook, goal G6 (kl_qp_2.gif) · PML Lecture 23 at 1:00:19 · Bishop, PRML, Fig. 10.2

The diagonal q must fit inside the tilted ellipse; its widths equal the target's conditional widths, √(1 − ρ²) = {{vik.g2d.formula}}, not the marginal widths, 1. That is Bishop's Figure 10.2.

The full q stores the covariance through a lower-triangular L with positive diagonal (torch's scale_tril), so LLᵀ is always a valid covariance. This matters again for linear regression (Part 8) and for why neural networks use the diagonal (Part 9).
