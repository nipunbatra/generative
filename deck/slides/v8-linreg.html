Two weights at once: VI for linear regression

The same neg_elbo, now with a 2-D $\theta$ and a 2-D Gaussian $q$. Bayesian linear regression has an exact posterior, so once more we can check the answer. If time is short, this part is homework: notebook N8.

The model, and the only new line ▶ N8

$y = 3x + 4 + \text{noise}$, and a Gaussian $q$ over (intercept, slope)

x = torch.linspace(-5, 5, n_points)
y = 3 * x + 4 + 5 * torch.randn(n_points)
prior = dist.MultivariateNormal(torch.zeros(2), torch.eye(2))

def log_joint(theta):                  # theta: [n, 2]
    mean = theta[:, :1] + theta[:, 1:] * x
    log_lik = dist.Normal(mean, 5.).log_prob(y).sum(-1)
    return log_lik + prior.log_prob(theta)

def neg_elbo(q, n=100):
    theta = q.rsample([n])
    return -(log_joint(theta) - q.log_prob(theta)).mean()

The PML notebook's data: noise of scale 5, prior $\theta\sim\N(0, I)$.

Each row of theta is one line; the likelihood scores it on every point.

The coin's neg_elbo, unchanged. Two choices of $q$: a diagonal Gaussian (two means, two widths) or a full one, $\Sigma = LL^\top$ (one more number, the tilt).

Nothing about VI changed. Only the model's log_joint and the shape of $q$.

Left: the exact posterior (blue contours) with the diagonal (purple) and full (teal) q's. They overlap because x is centred on zero: then intercept and slope are uncorrelated in the posterior (exact ρ = {{vik.linreg.n20.exact_rho}}), and a diagonal q loses nothing. The full q's fitted correlation, {{vik.linreg.n20.rho}}, is optimisation noise.

Right: 1,000 lines drawn from q; the band is ±2 sd of their predictions. This is epistemic uncertainty only (about θ), not the noise in y.
