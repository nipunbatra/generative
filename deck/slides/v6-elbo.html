The ELBO: a loss we can compute without the posterior

Parts 2–5 fitted $q$ to targets we could evaluate. The posterior is not one of them: we cannot evaluate $p(\theta\mid D)$, only $p(D\mid\theta)\,p(\theta)$. Three short algebra steps fix this.

The catch

The KL we want to minimise contains the posterior itself

$$\KL\big(q(\theta)\,\|\,p(\theta\mid D)\big) = \E_{\theta\sim q}\big[\log q(\theta) - \hl{\log p(\theta\mid D)}\big]$$
We can draw $\theta$ from $q$ and evaluate $\log q(\theta)$: we chose $q$.
$\log p(\theta\mid D)$ needs the evidence $p(D)$: the very integral from Part 1.

"If we could evaluate the posterior, we would not need $q$." So rewrite the KL using what we can evaluate.

PML Lecture 23 at 47:15–48:55 · Lecture 24 at 23:44

Everything so far used a target whose log-density we could compute at any point: a Gaussian, a mixture. The posterior's log-density is log p(D | θ) + log p(θ) − log p(D), and the last term is the problem.

Step 1 of 3 ✎ try it first

Substitute Bayes' rule for the posterior

$$\KL\big(q(\theta)\,\|\,p(\theta\mid D)\big) = \E_q\big[\log q(\theta) - \log p(\theta\mid D)\big]$$
$$p(\theta\mid D) = \frac{p(D, \theta)}{p(D)} \quad\Longrightarrow\quad \log p(\theta\mid D) = \log p(D, \theta) - \log p(D)$$
$$\KL = \E_q\big[\log q(\theta) - \log p(D, \theta) + \log p(D)\big]$$

$p(D, \theta) = p(D\mid\theta)\,p(\theta)$ is the joint: prior times likelihood, which we can evaluate.

Give students a minute to do the substitution in their notebooks before clicking. Log of a quotient is a difference of logs.

For the coin, log p(D, θ) = log Beta(θ; 5, 3) + 17 log θ + 13 log(1 − θ): Part 7's log_joint.

Step 2 of 3

The evidence does not depend on $\theta$, so it comes out of the average

$$\KL = \E_q\big[\log q(\theta) - \log p(D, \theta) + \log p(D)\big]$$
$$\KL = \E_q\big[\log q(\theta) - \log p(D, \theta)\big] + \log p(D)$$
The average of a constant is that constant: $\E_q[\log p(D)] = \log p(D)$.
$$\log p(D) = \underbrace{\E_q\big[\log p(D, \theta) - \log q(\theta)\big]}_{\text{call this }\ELBO(q)} + \KL\big(q(\theta)\,\|\,p(\theta\mid D)\big)$$

Rearranged: the evidence splits into a part we can compute and the KL we want to shrink.

PML Variational-Inference slides, "Evidence Lower Bound" 2 · PML Lecture 23 at 50:44–52:18

The last line is an identity: it holds for every q, good or bad. Moving log p(D) to the left and flipping signs gives it.

Step 3 of 3

KL $\ge 0$, so the ELBO is a lower bound on the log evidence

$$\log p(D) = \ELBO(q) + \KL\big(q(\theta)\,\|\,p(\theta\mid D)\big)$$
$$\log p(D) \;\ge\; \ELBO(q) = \E_{\theta\sim q}\big[\log p(D, \theta) - \log q(\theta)\big]$$
$\log p(D)$ is a fixed number: it does not depend on $q$.
So raising the ELBO lowers the KL, by exactly the same amount.

Maximise the ELBO, which needs only draws from $q$ and the joint. No evidence, no posterior.

PML Variational-Inference slides, "Evidence Lower Bound" 3 · PML Lecture 23 at 52:18–53:55

ELBO = Evidence Lower BOund. Equality holds exactly when the KL is zero, that is when q is the posterior.

It is an expectation under q, so Part 4's Monte Carlo estimates it, and Part 5's rsample gives its gradient. Every tool is now in place.

Two ways to write the same ELBO

What the code computes, and what the VAE lecture will use

$$\ELBO(q) = \E_q\big[\log p(D, \theta) - \log q(\theta)\big]$$
$$= \E_q\big[\log p(D\mid\theta) + \log p(\theta) - \log q(\theta)\big]$$
$$= \underbrace{\E_q\big[\log p(D\mid\theta)\big]}_{\text{fit the data}} \;-\; \underbrace{\KL\big(q(\theta)\,\|\,p(\theta)\big)}_{\text{stay close to the prior}}$$

The first form is what we will code for the coin. The second is the VAE's loss, with the prior $\N(0, I)$ and Part 2's Gaussian KL.

Split the log joint into likelihood plus prior, and group the prior with log q: E_q[log q − log p(θ)] is the KL from q to the prior. Note it is the prior here, not the posterior: both terms are computable.

Reading: the first term rewards q for putting mass on θ's that explain the data; the second penalises it for straying from the prior. Maximum likelihood is the first term alone with q a point mass.
