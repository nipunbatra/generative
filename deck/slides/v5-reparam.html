Gradients through random samples: the reparameterisation trick

We can estimate the KL to a mixture by sampling from $q$. To minimise it we need its gradient with respect to $q$'s parameters, and a random draw seems to have none.

The original formulation, as a computational graph

The loss depends on loc and scale only through a random draw

Backpropagation needs a derivative at every node. "Draw a sample" has none: the path is blocked.

PML notebook, cell 48 (reparam.001) · PML Lecture 23 at 35:26–37:46

Squares are deterministic functions: we know how their output changes with their input. The dashed circle is a random draw: run it twice with the same loc and scale and you get different θ_s.

What is "the derivative of a sample with respect to loc"? As drawn, the question has no answer: the sampler is a black box that hands back a number.

The same, in code ▶ N5

torch agrees: sample() cuts the graph

loc = torch.tensor(2.0, requires_grad=True)
scale = torch.tensor(0.5, requires_grad=True)
q = dist.Normal(loc, scale)
s = q.sample()
s.backward()
# RuntimeError: element 0 of tensors does not require grad
#               and does not have a grad_fn
The sample s is a plain number with no history. Any loss built from it, like kl_via_sampling, gives no gradient to loc or scale.

So we cannot yet train $q$ on the Monte Carlo KL. We need the randomness to sit somewhere else.

PML notebook, cell 39 · PML Lecture 24 at 9:27–10:15

torch is right to refuse: sample() draws with torch.no_grad(). The value of s does depend on loc and scale, but not through any operation autograd recorded.

The reparameterised formulation

Draw the noise from a fixed $\N(0, 1)$; then shift and stretch it

$$\varepsilon \sim \N(0, 1), \qquad z = \text{loc} + \text{scale}\cdot\varepsilon \quad\Longrightarrow\quad z \sim \N(\text{loc},\ \text{scale}^2)$$

✎Before the next click: what are $\partial z/\partial\,\text{loc}$ and $\partial z/\partial\,\text{scale}$?

PML notebook, cells 43–45 and 49 (reparam.002) · PML Lecture 23 at 38:53–41:33

Same distribution for z, different graph. The randomness now enters as an input, ε, which does not depend on any parameter. Everything between the parameters and the loss is a deterministic function, so backpropagation goes straight through.

Second click shows the answers: 1, and ε itself. Then check in code on the next slide.

Check the exercise in code ▶ N5

Now the draw has a gradient: $\partial z/\partial\,\text{loc} = 1$, $\partial z/\partial\,\text{scale} = \varepsilon$

torch.manual_seed(42)
loc = torch.tensor(2.0, requires_grad=True)
scale = torch.tensor(0.5, requires_grad=True)
eps = dist.Normal(0., 1.).sample()   # randomness that does not depend on loc or scale
z = loc + scale * eps                # the reparameterised draw
z.backward()
loc.grad, scale.grad, eps            # 1.0000, {{vik.rep.eps}}, {{vik.rep.eps}}

The gradient with respect to scale is the noise that was drawn. Different draw, different gradient: noisy but unbiased.

PML notebook, cell 44 · PML Lecture 24 at 11:02–13:26

With seed 42 the first standard-normal draw is ε = {{vik.rep.eps}}. Averaged over many draws, the gradient of E[f(z)] is E[f′(z)] for loc and E[f′(z) ε] for scale: exactly what averaging these per-draw gradients estimates.

You do not have to write it yourself ▶ N5

rsample is a reparameterised sample

# torch/distributions/normal.py
def rsample(self, sample_shape=torch.Size()):
    shape = self._extended_shape(sample_shape)
    eps = _standard_normal(shape, dtype=self.loc.dtype,
                           device=self.loc.device)
    return self.loc + eps * self.scale

z = dist.Normal(loc, scale).rsample()
z.backward()        # loc.grad = 1.0000, scale.grad = {{vik.rep.eps}}

Beta.rsample is reparameterised through Dirichlet/Gamma sampling with implicit gradients; that is why the coin's Beta q in Part 7 can be trained. A Poisson draw is an integer: a small change in its rate either leaves it unchanged or makes it jump, so there is no useful derivative.

Goal G4: fit a Gaussian to the mixture ▶ N5

Change sample to rsample, and the Monte Carlo KL trains

def kl_loss(q, n_samples=5000):
    sample_set = q.rsample([n_samples])                       # reparameterised
    return torch.mean(q.log_prob(sample_set) - p_s.log_prob(sample_set))
history = fit(TrainableNormal(loc=6.0, scale=0.1), kl_loss, steps=1500, lr=0.05)
