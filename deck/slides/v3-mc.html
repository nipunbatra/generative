Averages, and estimating them from samples

Variational inference's loss is an average over a distribution. We will almost never compute it exactly; we will estimate it from a handful of random draws. Here is why that works, and how noisy it is.

Notation for the rest of the lecture

$\E$ means "average over"

$$\E_{\theta\sim p(\theta\mid x)}[\theta] = 0.0002\times 0.2 + 0.127\times 0.5 + 0.873\times 0.8 = {{vik.three.pred}}$$
the three-coin posterior (Part 1): the chance the next toss is heads
$$\E_{\theta\sim \mathrm{Beta}(10, 4)}[\theta] = \int_0^1 \theta\;p(\theta\mid x)\,d\theta = \tfrac{10}{14} = {{vik.beta.mean}}$$
a continuous variable: the sum becomes an integral
$$\E_{z\sim q}\big[f(z)\big] = \int q(z)\,f(z)\,dz$$
in general: weight each value $f(z)$ by how likely $z$ is under $q$

The subscript says which distribution we average under. It will matter: KL and the ELBO are both averages, and the choice of subscript is the key decision in VI.

Posterior predictive: a posterior is not just for looking at; averages under it answer questions. The three-coin answer 0.762 and the Beta answer 0.714 differ because the priors differ.

Read "z ∼ q" aloud as "z drawn from q".

The one idea we need: Monte Carlo

Replace the integral by an average of draws

$$\E_{z\sim q}\big[f(z)\big] \;\approx\; \frac1S\sum_{s=1}^{S} f(z_s), \qquad z_s \sim q$$

Example: $q = \N(1,\ 0.5^2)$ and $f(z) = z^2$. Exact answer: $\E[z^2] = \mu^2 + \sigma^2 = 1 + 0.25 = 1.25$.

The variance of N(μ, σ²) is E[(z − μ)²] = σ², so E[z²] = μ² + σ². We use a case with a known answer so we can see the error.

The same q, N(1, 0.5²), and the same f(z) = z² come back in Part 6, where we need the gradient of this average.

How noisy is the estimate?

The error shrinks like $1/\sqrt{S}$

One draw of $z^2$ has a spread (standard deviation) of {{vik.mc.per_sd}}.

An average of $S$ draws has spread $1.061/\sqrt{S}$: {{vik.mc.th10}}, {{vik.mc.th100}}, {{vik.mc.th1000}} for $S$ = 10, 100, 1,000.

Measured over 2,000 repeats: {{vik.mc.s10}}, {{vik.mc.s100}}, {{vik.mc.s1000}}.

Centred on the right answer (unbiased), but noisy: 100 times more draws buy 10 times less noise.

For z ∼ N(μ, σ²), Var(z²) = 4μ²σ² + 2σ⁴ = 1 + 0.125, so the one-draw spread is √1.125 = 1.061. The average of S independent draws has variance Var/S.

Two facts to carry forward. Unbiased: on average the estimate is exactly right, which is all stochastic gradient descent needs. 1/√S: the cost of precision grows quickly, so in practice we use few draws (the VAE uses one per image).

In code

Three lines, in any number of dimensions

mu, sigma = 1.0, 0.5
z = mu + sigma * torch.randn(1000)   # 1,000 draws from q
estimate = (z**2).mean()             # about 1.25

Draw from $q$: standard noise, stretched by $\sigma$ and shifted by $\mu$. Remember this line: it returns in Part 6.

Average $f$: evaluate $f$ at each draw and take the mean. No integral anywhere.

The catch: we need draws from the distribution we average under. For a $q$ we chose, easy. For the posterior, that is the very problem we started with.

So variational inference will arrange for every average to be under $q$, never under the posterior.

With 100,000 draws this gives {{vik.mc.big}}. The same three lines work for a 32-dimensional z: draw a 32-vector of noise per sample. That is why Monte Carlo, unlike the grid, does not explode with dimension.
